# Carpetas, proyectos y páginas

- Una **página** es una lista de cosas: compras, entrenamiento, plan de viaje. Puede ser **lista**, **tarjetas** (buena para entrenar), **kanban** o **hábitos**.
- Una **carpeta** agrupa tus páginas. Ejemplo: la carpeta **Gimnasio** con Entrenamiento A y B.
- Un **proyecto** es una carpeta para hacer **con otras personas**. Ejemplo: el proyecto **Asado** con las listas Compras y Día, cada amigo con sus tareas.

## Cuándo usar cada uno

- Solo tú, algo que se repite: **carpeta**.
- Más gente, algo con inicio y fin: **proyecto**.
- Un entrenamiento para un alumno, un menú para un paciente: **envía la página** (ver "Enviar una página").

## Reinicio

Una página puede **reiniciar** sus marcas cada día, cada semana o cuando digas. Ideal para entrenamientos semanales y rutinas.

## Mover

En el menú de la página, **Mover a…** lleva la página (con sus tareas) a otra carpeta o proyecto.
