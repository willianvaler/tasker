# Pastas, projetos e páginas

- **Página** é uma lista de coisas: compras, treino, roteiro da viagem. Pode ser **lista**, **cards** (bom para treino), **kanban** ou **hábitos**.
- **Pasta** junta páginas suas. Exemplo: a pasta **Academia** com as páginas Treino A e Treino B.
- **Projeto** é uma pasta para fazer **com outras pessoas**. Exemplo: o projeto **Churrasco** com as listas Compras e Dia, e cada amigo com as tarefas dele.

## Quando usar cada um

- Só você, assunto que se repete: **pasta**.
- Mais gente, algo com começo e fim: **projeto**.
- Um treino para um aluno, um cardápio para um paciente: **envie a página** (veja "Enviar uma página").

## Reinício

Uma página pode **reiniciar** os checks todo dia, toda semana ou quando você mandar. Ótimo para treino semanal e rotinas.

## Mover

No menu da página, **Mover para…** leva a página (com as tarefas) para outra pasta ou projeto.

Para mudar a ordem sem arrastar, use **Mover para cima** e **Mover para baixo** no menu da pasta ou da página (no teclado, **Alt+↑** e **Alt+↓** com ela aberta).

## Academia

Se você respondeu que vai usar o app para treinar (ou ligou o **Modo academia** no Perfil), a barra lateral ganha o bloco **Academia**, com os seus treinos. **+ Novo treino** cria a página de treino direto ali, já em cards e reiniciando toda semana. Desligar o modo não apaga nada: a pasta Academia volta para Pastas.

## Barra lateral

Em **Perfil → Barra lateral** você muda a ordem dos blocos (Anotações, Pastas, Academia, Projetos, Recebidas) e esconde os que não usa. Vale em todos os seus aparelhos.
