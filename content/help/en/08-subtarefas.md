# Subtasks and levels

A task can have **subtasks**, and so can they. The default limit is **4 levels** (change it per page or project).

## Creating

- In the task panel, under **Subtasks**.
- In the list, `Tab` indents (makes it a child of the one above) and `Shift+Tab` brings it back.
- In bulk, indent with two spaces per level.

## How it counts

The parent is a **bundle**: its progress is its subtasks' ("2/5"), and it completes itself when the last one closes. Each subtask's weight (1 to 5) changes how much it counts.

## Codes

Press `W` to see codes like **1.2.3**. The **Outline** view shows the whole tree, and the page menu exports it as text.
